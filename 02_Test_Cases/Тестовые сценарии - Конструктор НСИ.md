# ТЕСТОВЫЕ СЦЕНАРИИ (маппинг из Use Case)

Система: Конструктор справочников НСИ (Национальный оператор «ОАО ЦНИИТУ»).
Покрываются Use Case: 01–15 (см. файлы `uc01_…`–`uc15_…`).
Правило маппинга: MSS каждого UC → базовый тест-сценарий; каждое расширение → негативный/альтернативный тест-сценарий; трассируемость в «Примечании» в формате `UC-NN/расширение`.

| Код сценария | Наименование сценария | Номер шага | Описание шага | Входящие данные | Результат шага | Примечание |
|---|---|---|---|---|---|---|
| ТС-01 | Создание нового справочника | UC-01/1–7 | Пользователь нажимает «Создать справочник» | Роль Бизнес-аналитик, свободный код | Черновик создан, конструктор открыт, паспорт пуст, схема пуста, справочник в «Мои справочники» | MSS UC-01 |
| ТС-02 | Создание с дублирующим кодом | UC-01/1a | Пользователь создаёт справочник с кодом, занятым в реестре | Код уже существует | Выполнена проверка реестра, показана причина, черновик не создан | UC-01/1a → UC-10 |
| ТС-03 | Создание без прав | UC-01/2a | Пользователь без прав нажимает «Создать справочник» | Роль без права создания | «Недостаточно прав для выполнения операции», черновик не создан | UC-01/2a → UC-15 |
| ТС-04 | Заполнение паспорта нового справочника | UC-02/1–8 | Пользователь заполняет все поля паспорта | Валидные данные: код ≤100, наименование ≤3000 | Паспорт заполнен, карточка «Справочник» обновлена, тип «Пользовательский», дата окончания «Бессрочно» | MSS UC-02 |
| ТС-05 | Паспорт с дублирующим кодом | UC-02/2a | Пользователь вводит существующий код | Код занят | Показана причина, поля исправляются | UC-02/2a |
| ТС-06 | Уточнение паспорта опубликованного справочника | UC-02/4a | Пользователь редактирует паспорт опубликованного справочника, добавляет новое поле | Опубликованный справочник | Только добавление новых элементов; наименование/тип/код/структура заблокированы | UC-02/4a |
| ТС-07 | Тип «Защищенный (классификатор)» | UC-02/3 | Пользователь выбирает тип «Защищенный (классификатор)» | Валидные данные | Тип сохранён, доступ к справочнику только для пользователей организации | UC-02 (вариация шага 3) |
| ТС-08 | Добавление корневого поля схемы | UC-03/1–7 | Пользователь нажимает «Добавить поле», заполняет код/название/тип/обязательность | Валидные атрибуты поля | Поле отображено в таблице схемы | MSS UC-03 |
| ТС-09 | Добавление вложенного поля (объект) | UC-03/7a | Пользователь раскрывает объект и добавляет дочернее поле | Объект в схеме | Дочернее поле добавлено на вложенном уровне | UC-03/7a |
| ТС-10 | Поле с дублирующимся кодом | UC-03/6a | Пользователь добавляет поле с существующим кодом | Код поля дублируется | Показана причина, поле не добавлено | UC-03/6a |
| ТС-11 | Импорт валидной JSON-схемы | UC-04/1–6 | Пользователь загружает корректный JSON-файл схемы | Валидный JSON | Схема применена, все поля (включая вложенные) в таблице | MSS UC-04 |
| ТС-12 | Импорт невалидного JSON | UC-04/3a | Пользователь загружает файл с синтаксической ошибкой | Неверный JSON | Показана позиция и суть ошибки, схема не изменена | UC-04/3a |
| ТС-13 | Импорт схемы с неизвестным типом | UC-04/4a | Пользователь загружает JSON с неизвестным типом поля | Неверный тип | Перечислены некорректные элементы, схема не изменена | UC-04/4a |
| ТС-14 | Схема из одного активного справочника | UC-05/1–6 | Пользователь выбирает один активный справочник | Активный справочник в реестре НСИ | Схема сформирована из его структуры и отображена | MSS UC-05 |
| ТС-15 | Реестр НСИ недоступен | UC-05/2a | Пользователь запускает генерацию при недоступном реестре | Реестр НСИ не отвечает | Показана причина, схема не изменена | UC-05/2a |
| ТС-16 | Нет активных справочников | UC-05/3a | Пользователь запускает генерацию при пустом реестре | Реестр пуст | «Нет доступных активных справочников» | UC-05/3a |
| ТС-17 | Сохранение заполненного черновика | UC-06/1–6 | Пользователь нажимает «Сохранить справочник» | Заполненный паспорт + схема | «Черновик создан», черновик в списке, доступен повторный вход | MSS UC-06 |
| ТС-18 | Сохранение с незаполненными обязательными полями | UC-06/2a | Пользователь сохраняет справочник без кода | Пустой код | «Заполните поля справочника», поля выделены, черновик не сохранён | UC-06/2a |
| ТС-19 | Сохранение при недоступном сервере | UC-06/3a | Пользователь сохраняет при обрыве связи | Сервер недоступен | «Нет связи с сервером», локальные изменения сохранены в конструкторе | UC-06/3a |
| ТС-20 | Публикация сохранённого черновика | UC-07/1–7 | Пользователь нажимает «Опубликовать» | Сохранённый черновик | Новая ревизия с номером/датой, справочник активный, записи read-only | MSS UC-07 |
| ТС-21 | Публикация несозданного черновика | UC-07/1a | Пользователь публикует без сохранения | Несохранённые изменения | «Сначала сохраните справочник», автосохранение (UC-06), затем публикация | UC-07/1a → UC-06 |
| ТС-22 | Публикация без определяемой ревизии | UC-07/2a | Публикация при конфликте ревизий | Некорректная ревизия | «Не удалось определить ревизию для редактирования» | UC-07/2a |
| ТС-23 | Повторная публикация без черновика | UC-07/4a | Пользователь повторно публикует активный справочник | Опубликованный справочник | «Опубликованный справочник необходимо сначала перевести в черновик» → UC-08 | UC-07/4a → UC-08 |
| ТС-24 | Перевод опубликованного в черновик | UC-08/1–5 | Пользователь нажимает «Редактировать» опубликованного справочника | Активный справочник | Копия ревизии в черновик, паспорт/структура редактируемы, ревизия в истории | MSS UC-08 |
| ТС-25 | Перевод без прав | UC-08/2a | Пользователь без прав переводит в черновик | Недостаточно прав | «Недостаточно прав для выполнения операции» | UC-08/2a |
| ТС-26 | Конфликт ревизий при переводе | UC-08/3a | Перевод при чужом активном редактировании | Конфликт | «Не удалось начать редактирование», справочник опубликован | UC-08/3a |
| ТС-27 | Редактирование справочника с записями | UC-09/1–7 | Пользователь уточняет паспорт + добавляет поле, публикует | Справочник с записями | Новая ревизия, записи сохранены, изменения отображены | MSS UC-09 |
| ТС-28 | Попытка изменить код опубликованного | UC-09/3a | Пользователь пытается изменить код/наименование | Опубликованный справочник с записями | Блокировка: «наименование, тип, код и существующую структуру менять нельзя» | UC-09/3a |
| ТС-29 | Изменения несовместимы с записями | UC-09/5a | Пользователь вносит несовместимые изменения схемы | Несовместимые поля | Перечислены несовместимые элементы | UC-09/5a |
| ТС-30 | Просмотр реестра НСИ | UC-10/1–5 | Пользователь открывает «Реестр НСИ» | Вошёл в систему | Разделы «Редактируемые» + справочники со статусами, выбор открывает конструктор | MSS UC-10 |
| ТС-31 | Загрузка реестра при сбое сервера | UC-10/2a | Пользователь открывает реестр при недоступном сервере | Сервер не отвечает | «Не удалось загрузить справочники», доступен повтор | UC-10/2a |
| ТС-32 | Открытие недоступного справочника | UC-10/5a | Пользователь выбирает справочник без прав | Права отозваны | «Не удалось открыть справочник» / «Запрошенный ресурс не найден» | UC-10/5a |
| ТС-33 | Создание записи в черновике | UC-11/1–7 | Пользователь создаёт запись по схеме | Черновик с записями | Запись с номером сохранена, отображена в списке | MSS UC-11 |
| ТС-34 | Создание записи в опубликованном | UC-11/1a | Пользователь пытается создать запись в активном справочнике | Опубликованный справочник | «Записи опубликованной ревизии доступны только для просмотра» → UC-08 | UC-11/1a → UC-08 |
| ТС-35 | Запись с незаполненными обязательными полями | UC-11/4a | Пользователь сохраняет запись с пропусками | Пропущенное обязательное поле | Поля выделены, запись не сохранена | UC-11/4a |
| ТС-36 | Просмотр записей черновика | UC-12/1–5 + 2a | Пользователь открывает записи черновика | Черновик | Режим редактирования: создание/изменение доступно (UC-11) | UC-12/2a → UC-11 |
| ТС-37 | Просмотр записей опубликованной ревизии | UC-12/1–5 + 2b | Пользователь открывает записи активного справочника | Опубликованный | Read-only: «Записи опубликованной ревизии доступны только для просмотра» | UC-12/2b |
| ТС-38 | Запись пономерно | UC-12/4 | Пользователь открывает карточку конкретной записи | Выбранная запись | Карточка записи с номером и значениями | UC-12 (вариация шага 4) |
| ТС-39 | Удаление черновика | UC-13/1–6 | Пользователь удаляет свой черновик и подтверждает | Черновик в списке | «Черновик удален», исключён из «Мои справочники» | MSS UC-13 |
| ТС-40 | Отмена удаления черновика | UC-13/2a | Пользователь отменил подтверждение удаления | Черновик в списке | Возврат в список, черновик сохранён | UC-13/2a |
| ТС-41 | Сбой удаления черновика | UC-13/4a | Удаление при недоступном сервере | Сервер не отвечает | «Не удалось удалить черновик», черновик сохранён | UC-13/4a |
| ТС-42 | Просмотр истории ревизий | UC-14/1–5 | Пользователь открывает историю ревизий | Справочник с ≥1 ревизией | Список ревизий: номера, статусы, «Добавил/Изменил/Удалил», исполнители, даты | MSS UC-14 |
| ТС-43 | Сбой загрузки истории | UC-14/2a | Пользователь открывает историю при сбое | Сервер не отвечает | Показана причина (HTTP-ошибка), доступен повтор | UC-14/2a |
| ТС-44 | Изменение активной ревизии | UC-14/4a | Пользователь выбрал активную ревизию для изменения | Активная опубликованная | Выполнен перевод в черновик (UC-08), ревизия отображена | UC-14/4a → UC-08 |
| ТС-45 | Назначение роли Бизнес-аналитик | UC-15/1–6 | Руководитель назначает пользователю роль | Организация, пользователи | Роль применена, пользователь видит свои справочники | MSS UC-15 |
| ТС-46 | Операция без прав | UC-15/1a | Пользователь выполняет операцию без прав | Недостаточно прав | «Недостаточно прав для выполнения операции» | UC-15/1a (precondition всех UC) |
| ТС-47 | Истёкшая сессия | UC-15/5a | Руководитель применяет изменения после истечения сессии | Истёкший токен | «Сессия истекла, войдите заново» | UC-15/5a |

| Код | Сценарий | Ожидание |
|---|---|---|
