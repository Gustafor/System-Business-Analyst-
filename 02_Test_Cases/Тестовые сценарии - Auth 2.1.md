# ТЕСТОВЫЕ СЦЕНАРИИ (маппинг из Use Case)

Подсистема: вход и авторизация через Google Identity Platform (OAuth 2.1 / OIDC).
Покрываются Use Case: 01 Log In to System, 02 Access Protected Data, 03 Renew Access Token, 04 Log Out from System, 05 Revoke User Tokens.

Правила построения:
- Базовый сценарий каждого UC строится по основному потоку; номер шага в тест-сценарии = номер шага MSS.
- Каждый негативный/альтернативный сценарий соответствует одному расширению; в столбце «Примечание» — трассируемость `UC-NN/ветвление`.
- «Входящие данные» негативного сценария — провоцирующий ввод (сбой, невалидный токен, отказ).

Легенда кодов: UC-01 Log In to System · UC-02 Access Protected Data · UC-03 Renew Access Token · UC-04 Log Out from System · UC-05 Revoke User Tokens.
